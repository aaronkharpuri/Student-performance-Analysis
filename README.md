Student Performance Analysis

Overview
An end-to-end data analysis project exploring factors that influence student academic outcomes using the UCI Student Performance dataset (395 students, 33 variables).

Tools and Libraries
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Google Colab

Project Phases
- Phase 1 — Data collection and setup
- Phase 2 — Exploratory data analysis
- Phase 3 — Feature engineering and hypothesis testing
- Phase 4 — Predictive modelling (Logistic Regression, Random Forest, Decision Tree)
- Phase 5 — Summary dashboard and presentation

Key Findings
- 74.2% of students passed the Mathematics course
- Absences is the strongest predictor of student failure
- Past failures significantly lower final grades (p=0.000)
- Higher education aspiration linked to better outcomes (p=0.032)
- Sex has no significant effect on grades (p=0.053)
- Best model: Logistic Regression with 80.6% accuracy

Dataset
UCI Machine Learning Repository — Student Performance Data Set
https://archive.ics.uci.edu/ml/datasets/student+performance
